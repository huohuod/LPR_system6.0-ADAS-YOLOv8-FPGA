# LPR_system6.0-ADAS-YOLOv8-FPGA
本仓库为本队伍2026嵌入式系统芯片设计竞赛紫光同创赛道赛题三「芯眸智驾」全套软硬件源码仓库。项目基于紫光同创FPGA开发平台，采用软硬件协同架构，以四路视频分屏可视化方案，融合深度学习与传统机器视觉双路感知。系统可实时采集多视角画面，模拟车前、车后、左后、右后方来车感知，依托深度测距实现碰撞风险预警；同时对复杂路口场景下的车道辅助线、红绿灯、机动车、行人、斑马线目标完成实时检测识别，对车辆行驶区域内的车道实线与虚线进行标记，支持车辆ID跟踪，判别车辆、行人闯红灯违规行为，及时提醒驾驶员安全行驶、合理保持跟车距离。

## 仓库内容
- FPGA 核心硬件代码（PDS 工程、RTL、约束、仿真文件）
- 上位机核心驱动代码
- ADAS 车辆辅助驾驶系统程序
- YOLOv8 检测模型部署工程 lpr_system_v6.0
